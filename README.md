# password-strength-checker
A simple tool to evaluate password strength based on security best practice

## Overview
This project checks the strength of a password based on common security best practices.

## Why this project?
Weak passwords are one of the most common security vulnerabilities. This tool helps demonstrate basic secure coding principles.

## Features
- Checks password length
- Detects uppercase and lowercase letters
- Detects numbers and special characters
- Classifies passwords as Weak, Medium, or Strong
- ## Advanced Improvements
- Password scoring system
- Detection of common weak passwords
- Actionable security feedback
- Strong password generation


## Tools Used
- Python
- Regular Expressions (re)
